FEATURED PROJECT · 01 / WEB DEVELOPMENT IN DEVELOPMENT

PrintSafe

File handling should feel private—not like a leap of faith.

Many online tools ask people to upload files without making it clear where data goes or what metadata might remain. PrintSafe is a browser-based platform I’m building to explore local processing for sensitive files and reduce unnecessary uploads.

Browser-basedPrivacy-focusedLocal processing goal
Project focus

The aim is private and transparent file handling. Local processing is a design goal; the complete product and all operations are not claimed as finished.

FEATURED PROJECT · 02 / WEB DEVELOPMENT IN DEVELOPMENT

Timetable Generator

Less clash whack-a-mole. More room to learn.

I’m building a tool to help organize university schedules. The idea is to enter departments, subjects, teachers, and rooms, then generate a clash-free schedule.

HTMLCSSJavaScript
Project focus

Make semester scheduling clearer by considering the people, subjects, and rooms in a university timetable.
